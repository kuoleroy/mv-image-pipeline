# 已验证配方

以下配方来自实际完成的三个成片，全部通过解码零报错校验。

## 配方 A：抖音竖屏 90 秒

| 项 | 值 |
|---|---|
| 画布 | 1080x1920 |
| 帧率 | 30fps |
| 时长 | 85.74s |
| 镜头数 | 38（每镜 2.26s） |
| 素材 | 竖屏 864x1536，超分到 1458x2592 |
| 码率 | 约 5.4 Mbps |

**结构**（从原曲 104.22s 切到 189.96s）：

```
副歌2(4句) → 间奏 → 桥段(回来/学会一个人/琴弦) → 副歌3(4句) → 间奏 → 灯/门/路过/没听见
```

切点不是为了凑时长，是为了保住 A-B-A-C 的完整结构，而且**结尾是真的结尾**。音乐视频断在半句上，前面攒的完播全部作废。

**开场巨字**：`LXGW WenKai Mono` / 藏青 `&H004A3422` / size 156 / y=1220 / 描边 3.5 同色 / 只停到 2.60s

**标题**：`<歌名>｜原创歌曲，写给所有不吵了的人`

**平台动作**：勾选「内容由 AI 生成」；不关联错配热点；电脑端不关联正式音源。

## 配方 B：B站横屏「双世界」190 秒

| 项 | 值 |
|---|---|
| 画布 | 1920x1080 |
| 帧率 | 30fps |
| 时长 | 189.96s |
| 镜头数 | 80（每镜 2.4s） |
| 素材 | 横屏 1536x864，超分到 2592x1458 |
| 码率 | 约 9.3 Mbps |

**双世界换池规则**：

```
主歌 / 尾声  → 写实（她忍着的那个真房间）
副歌 1/2/3   → 二次元（她喊出来的那个世界）
间奏         → 二次元空镜（城市、雨、无人的房间）
桥段         → 二次元淡彩（回忆）
```

**镜头排序**：逐段手排，不按池顺序取。每个池生成了 12-18 张，成片只用 7-9 张，挑最好的按景别起伏排列，比顺序取能明显拉开节奏。

每个副歌走「全景建立 → 逐步收紧 → 特写砸下 → 再放开」的呼吸，相邻两镜不重复景别。

**间奏特判**：13.5 秒的空镜，4 个镜头太拖，扩到 6 个（每镜 2.25s）。

**首尾呼应**：尾声那一组故意复用主歌的机位（绕一圈回到同一个房间）。

**字幕**：`Noto Sans SC`（可变字体，渲染成极细 Thin，这是要的效果）

| 段 | size | spacing | tone |
|---|---|---|---|
| 主歌1 写实亮房间 | 74 | 4 | ink |
| 副歌1 黄昏城市 | 95 | 4 | ink |
| 主歌2 写实室内 | 74 | 4 | ink |
| 副歌2 雨夜极暗 | 95 | 4 | light |
| 桥段 淡彩极亮 | 82 | 7 | pale |
| 副歌3 暗调逆光 | 100 | 4 | light |
| 尾四句 | 67/64/62/59 | 9 | ink |

**话题**：截图里的「直拍星计划、闪耀的Producer、电台新星征集令、上B站看播客、高能量自律、音乐分享官」都不参加，内容与活动不匹配。真正匹配的是「新世代音乐人计划」对应 AI/手搓赛道，需自行搜索并投稿音乐区。

## 配方 C：视频号竖屏 60fps

| 项 | 值 |
|---|---|
| 画布 | 1080x1920 |
| 帧率 | **60fps** |
| 时长 | 85.73s |
| 镜头数 | 38 |
| 素材 | 竖屏 864x1536，超分到 1458x2592 |
| 码率 | 约 8.4 Mbps |

**做法**：读 90 秒版时间轴，**段边界与每段镜头数完全不动**，只把 ids 换成竖屏机位库 Y01-Y80。这样音频时长、叠化算法都不用重算，字幕文件也能直接复用。

**校验三条**（缺一不可）：

```python
if len(ids) != len(s["ids"]):
    raise SystemExit("段 %s 镜头数不符：源 %d / 新 %d")
```

镜头数变了节奏就变了。还要查重复镜数、相邻重复数。

**字幕重调**：90 秒版的墨字是给真人实拍版调的（背景米白墙，开场帧亮度 176），竖屏动画版是雨夜暗调（Y01 平均亮度约 60），墨字等于消失。

分档：

| 段 | 时间 | 档 |
|---|---|---|
| 雨夜段 K1 / K3 | 4.56-20.40 / 43.47-63.84 | 米白字 + 深描边，删掉白晕 |
| 淡彩段 K2 | 22.32-43.71 | 墨字实心，几乎不要描边 |
| 清晨段 K4 | 65.25-85.20 | 墨字 + 白描边 + 加粗（字号 70→84） |
| 巨字 K0 | 0.00-2.60 | 保留藏青（底下是白床单，够亮） |

G1-G4 是白色柔光层，只为亮背景设计，在暗场会变成脏白晕 —— 直接删掉，改用深色描边做分离。

**平台动作**：**手机相册直传或「视频号助手」网页上传**，不要经微信聊天窗口传，否则可能被压成 640p。

## 通用质量门禁

任何版本交付前必须过：

1. `python scripts/mv_qc.py check 成片.mp4` → **解码零报错**
2. 字幕重叠扫描 → **零真实重叠**
3. 字幕在目标帧可读（放大取像素看，别信缩略图）
4. 相邻镜不重复景别
5. 平台规格对（分辨率/帧率/码率/时长）

## 已知的遗留问题

- **90 秒版及其派生的字幕曾漏掉收紧算法**，残留 0.24s 重叠（K2 39.45→43.71，下句 K3 起于 43.47）。`subs_build.py` 已内置该算法，换流程后仍要验证。
- 断行：巨字按字数均分，不管语义，可能断在词中间。
- 逐字精度：按字数均分，快段差半拍。真数据在 MFA 的 `words` 层。
- 旧目录里的方形废弃图未清理，删除需用户明确授权。
